# Folio PC · 藏语练习册

[English](README.md) | 中文

Folio 是配合《拉萨口语读本（课堂教学）》使用的 Windows 离线练习册。你可以学习藏语生词、练习阅读和造句，并在词语到期时再次复习。界面支持中文和 English。

**[下载 Windows 版 Folio](https://github.com/Tyanmood/folio-pc-releases/releases/latest/download/FolioSetup.exe)** · [更新说明](https://github.com/Tyanmood/folio-pc-releases/releases/latest)

## 练习册包含什么？

- **第 1–7 课**有专门的学习活动。第 1 课介绍藏文字母和发音，后续课程包含对话、语法解释、翻译和造句。**第 8–17 课**会随着我们的学习进度逐步发布。
- **生词学习**支持选择一课或合并多课。每轮最多学习十个新词，可以按课本顺序或混合顺序学习。选择词义适合较简单的练习，翻面词卡则需要先回忆，再显示释义并自行判断，难度更高。
- **复习**会随着你逐渐记住词语而延长复习间隔，答错的词会更早再次出现。你也可以提前复习、补全藏文拼写，或输入中文释义。
- **听读练习**支持在文章中点词查义、标记停顿。你可以单独调大藏文字号，也可以为练习册选择黑色主题。
- **导入书页**可以从照片或粘贴的列表中生成个人生词表。保存前可以核对和修改词条。

## 在 Windows 上开始使用

1. 联网运行 **FolioSetup.exe**。如果安装程序询问是否已经使用 Folio，新用户选“否”，已有练习册的用户选“是”，再选择原来的 **Folio PC.html**，以保留学习进度。
2. 用浏览器打开 **Folio PC.html**。新安装的文件位于**文档 → Folio PC**文件夹中。安装后即可离线练习。
3. 打开**我的学习手册**，选择课程，再点击**学习新词**。设置顺序和难度后，点击**开始学习**。下次打开**复习**即可查看哪些词语到期了。

Folio 将答案、阅读标记和录音保存在浏览器配置中。下次使用同一个浏览器配置打开同一个文件，即可继续学习。

## 更新

联网打开练习册时，Folio 会自动检查 GitHub 上的更新。看到**下载并安装更新**后，点击即可在原位置更新练习册。当前公开版本为 **Folio PC 1.1**，对应的 GitHub 构建标签为 `v1.3.1`，旧版可能会在更新提示中显示这个编号。
